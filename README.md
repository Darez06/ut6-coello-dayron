Aplicación web estática desarrollada para gestionar y presentar servicios digitales mediante control de versiones con Git y GitHub.

## Tecnologías empleadas
- HTML5
- CSS3
- JavaScript (ES6)
- Git y GitHub

## Estructura del proyecto
- `index.html`: Estructura principal de la aplicación y sección de contacto.
- `css/estilos.css`: Hoja de estilos, paleta de colores personalizada y modo oscuro.
- `js/app.js`: Lógica de filtrado de tarjetas y alternancia de tema.
- `assets/icono.svg`: Logotipo e icono vectorial.
- `.gitignore`: Reglas de exclusión de archivos temporales y sensibles.

## Ejecución
No requiere servidor ni dependencias externas. Basta con abrir el archivo `index.html` directamente en cualquier navegador web moderno.

## Funcionalidades incorporadas
- Filtrado dinámico de tarjetas de servicios y modo oscuro.
- Identidad visual y paleta de colores personalizadas.
- Sección de contacto integrada mediante flujo de ramas (`feature/contacto`).
- Mensaje de portada actualizado tras resolución de conflicto (`feature/mensaje`).
